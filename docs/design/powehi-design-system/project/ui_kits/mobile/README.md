# Powehi · Mobile UI Kit

Mobile-first screens. Three iOS frames side by side: Welcome, Chat list, Conversation.

Atoms (Logo, Avatar, Button, IconBtn, Icon) are shared with the web kit (`../web/`).

## What this does NOT do
- Static frames — no inter-screen navigation. Use the web kit for interactive flow.
- No keyboard shown in the conversation view.
- Tab bar items beyond Chats are decorative.
